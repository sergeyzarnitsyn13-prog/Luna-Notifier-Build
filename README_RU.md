# Luna — Owner-only тестовый клиент Systematic 3.57

Это ИЗОЛИРОВАННЫЙ тест доставки одного фиксированного сообщения, а не готовая production-система.

**Что делает:** Luna находится только в трее Windows, открывает утверждённый MoonGlow-бабл по двойному щелчку или по сигналу из тестового сайта владельца.

**Что НЕ делает:** не читает Firestore, не обращается к внешним серверам, не хранит токены/пароли, не видит список сотрудников, не обрабатывает реальные задачи, не запускается автоматически при старте Windows и не показывает постоянное окно.

## Проверка

1. Скомпилировать Windows EXE вне рабочих ПК, например на GitHub Actions (workflow включён в исходники). Выгрузить один файл `Luna.OwnerTest.exe` из artifacts сборки. Исходный ZIP не содержит проверенного EXE.
2. Проверить исполняемый файл корпоративным антивирусом и при необходимости согласовать запуск с ИТ. Цифровой подписи пока нет; возможен SmartScreen или запрет политиками компании.
3. На своём ПК запустить `Luna.OwnerTest.exe` без прав администратора. Луна должна появиться в трее. Двойной щелчок показывает локальный бабл.
4. На том же ПК открыть ТОЛЬКО staging: `https://d5d1foolkgopgtskjhcv.d8epmcec.apigw.yandexcloud.net/` (Systematic 3.57), войти под владельцем через личный пароль.
5. В инструментах владельца нажать «Тест Luna». Если браузер запросит разрешение на доступ к локальным сетевым устройствам, разрешить именно тестовому сайту. Луна показывает фиксированный бабл, а сайт — подтверждение. Если блокирует политика браузера, сообщить, не отключая защиту глобально.
6. Проверить: выход владельца скрывает кнопку; иной профиль не видит её; при остановленной Luna сайт сообщает о недоступности; другие сайты не могут использовать локальный endpoint через браузер.

## Безопасность теста

- TCP-сервер принимает соединения только на `127.0.0.1:58731`. Он не публикует порт в сети и не использует внешние службы.
- Допускается только POST `/luna/test`, только с заголовками `Origin` и `Host`, точно соответствующими staging и loopback. OPTIONS предназначен только для CORS/Chrome Local Network Access.
- Сайт перед отправкой проверяет действительный **серверный** owner session через `/__owner_status`. Никаких данных задач или паролей к Luna не передаётся.
- Luna показывает заранее встроенный текст: «Тестовое уведомление из Systematic.»; произвольный текст, команды и ссылки не принимаются.
- Минимальный интервал сигналов — 2 с. Запрос не зависит от Firestore, сайт не создаёт новых подписок.
- `Origin` является browser-side ограничением; локальное приложение того же пользователя может его подделать. Это допустимо ТОЛЬКО для фиксированного тестового бабла без конфиденциальной информации, **НЕ** для защищённой привязки учётных записей.
- Для настоящей фоновой доставки при закрытом браузере потребуется серверное хранилище и привязанный device token. Эту реализацию в прототип не включали.

## Сборка

`Luna.OwnerTest.csproj` — классический WPF .NET Framework 4.8, без NuGet. Workflow `.github/workflows/build-luna-owner-test.yml` собирает один `Luna.OwnerTest.exe` на Windows runner. Он не требует администраторских прав на клиенте и не устанавливает приложение.

Windows EXE в этом окружении не собирался и не запускался. Работа в корпоративном браузере и на рабочем Windows ПК должна быть подтверждена отдельно.
